# Security policy

This is a privileged administration tool. Trust the deployment directory,
root account, virtual environment and pinned upstream source. Read
[security design](docs/SECURITY.md) for boundaries and limitations.

Keep configs/backup directories private. Do not attach secrets to reports.
Contact your deployment maintainer privately for vulnerabilities. No hosted
reporting service, SLA, certification or ongoing monitoring service is implied.
Recheck upstream advisories, Ubuntu notices/CVE tracker and dependency versions
before deployment. Absence of a published advisory is not proof of security.
